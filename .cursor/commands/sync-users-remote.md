# Sync users remote

Проверь `backups/users.tsv`: первая строка `login<TAB>password`, дальше пары через таб, коды в верхнем регистре, без пустых строк и дублей login.

Если файл в порядке, выполни:

```bash
npm run sync:users:remote
```

Скрипт откроет SSH-туннель и обновит базу `u1526758_patterns` на REG.RU. Сообщи результат. Если SSH недоступен — напиши, что нужно запустить команду вручную с вашей машины.
