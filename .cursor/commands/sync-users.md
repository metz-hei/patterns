# Sync users

Проверь `backups/users.tsv`: первая строка `login<TAB>password`, дальше пары через таб, коды в верхнем регистре, без пустых строк и дублей login.

Если файл в порядке, выполни:

```bash
npm run sync:users
```

Сообщи, сколько пользователей загружено. Если есть ошибки валидации — покажи проблемные строки и не запускай команду.
